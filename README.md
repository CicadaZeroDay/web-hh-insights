# WEB-HH Insights

Auto-generated companion site for [web-hh.com](https://web-hh.com) — the job board
for affiliate marketing, media buying and crypto teams.

Pages are regenerated daily by a GitHub Action from the public blog feed
(`/api/blog/list`) and served via GitHub Pages. Each page links back to the full
article and job hubs on web-hh.com.

- Generator: [`generate.mjs`](generate.mjs)
- Workflow: [`.github/workflows/publish.yml`](.github/workflows/publish.yml)
- Output: [`docs/`](docs/)
